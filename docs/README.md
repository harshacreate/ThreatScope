# Screenshots

Add a screenshot here so the main README and your GitHub/LinkedIn preview look complete:

1. Run the app (`docker compose up --build -d`) and open it in your browser.
2. Take a screenshot (macOS: Cmd+Shift+4, drag over the window).
3. Save it as `threatscope-preview.png` in this folder, then:
   ```bash
   git add docs/threatscope-preview.png && git commit -m "Add dashboard screenshot"
   ```
4. (Optional) re-add it at the top of the main README:
   ```markdown
   ![ThreatScope](docs/threatscope-preview.png)
   ```
